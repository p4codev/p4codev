## 🏗️ How I think about architecture

> One reference blueprint, portable across the three clouds. Swap the boxes, keep the pattern.

```mermaid
flowchart LR
    subgraph SRC["📥 Sources"]
        A1[(Databases)]
        A2[APIs / SaaS]
        A3[Events / IoT]
    end

    subgraph ING["⚡ Ingestion & Streaming"]
        B1["Kafka · Kinesis\nPub/Sub · Event Hubs"]
    end

    subgraph LAKE["🪣 Lakehouse"]
        C1["S3 · GCS · ADLS"]
        C2["Spark · Databricks\nDataflow · Glue"]
    end

    subgraph DWH["🏛️ Warehouse & Serving"]
        D1["BigQuery · Redshift\nSynapse · Snowflake"]
        D2["dbt · Airflow · Composer"]
    end

    subgraph AI["🧠 AI Layer"]
        E1["Vertex AI · Bedrock\nAzure OpenAI"]
        E2["RAG · Agents · MLOps"]
    end

    subgraph OUT["📊 Consumers"]
        F1[Dashboards]
        F2[APIs & Apps]
        F3[LLM Assistants]
    end

    SRC --> ING --> LAKE --> DWH --> OUT
    LAKE --> AI --> OUT
    DWH --> AI
```
